Check your download

Each command-line release has a SHA256SUMS file. Download it next to your files and run:

{% call code_block("Verify checksums", compact=True) -%} $ shasum -a 256 -c SHA256SUMS --ignore-missing {%- endcall %}

Build from source

Every app and the server build from the same repository. You'll need Go 1.26 or later, Node 24 and, for the iPhone app, Xcode.

{% call code_block("Build from source", compact=True) -%} $ git clone {{ repository_url }} $ cd hisar && make build {%- endcall %}
